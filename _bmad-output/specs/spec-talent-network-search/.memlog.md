- (decision) Initiate spec-talent-network-search from user requirements and talent-graph-seed.json
- (capability) CAP-1: Import and store talent data (people, employment, skills, referrals) idempotently from JSON seed data without duplicating records or connections.
- (capability) CAP-2: Identify valid professional connections based on overlapping company employment intervals or bidirectional referrals.
- (capability) CAP-3: Search and discover people matching a required skill reachable within up to 2 professional connections from a selected person.
- (capability) CAP-4: Return each matching person alongside their explicit, human-readable connection chain.
- (constraint) Graph traversal depth is strictly capped at 2 hops.
- (constraint) Referrals are strictly bidirectional connections usable from either party.
- (constraint) Employment overlap requires identical company name and overlapping date intervals [from, to], with null to interpreted as current/ongoing.
- (constraint) Re-importing data must be fully idempotent with zero duplicated nodes or edges.
- (decision) Create companions data-schema.md and connection-rules.md for schema specification and date overlap mathematics.
- (assumption) Date granularity is YYYY-MM; equal start and end months constitute an active overlap during that month.
- (assumption) Referrals without dates are permanently active bidirectional connections.
- (assumption) Company names are matched case-insensitively with trimmed whitespace.
